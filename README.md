# 蒋文华·博弈论50讲 Perspective

> 用博弈论的眼光看世界，把现实冲突翻译成策略语言。

## 什么是这个 Skill

这个 Skill 基于浙江大学蒋文华老师的《博弈论50讲》课程体系，将博弈论的核心概念、分析框架和思维方式提炼为可运行的思维操作系统。

当你遇到利益冲突场景时，用这个 Skill 可以帮你：

- 快速识别这是哪种博弈结构（囚徒困境？智猪博弈？信号博弈？）
- 找到这个博弈的纳什均衡（稳定状态在哪里）
- 分析为什么是那个结果（个体理性 vs 集体理性）
- 找到破局点（怎么改变游戏规则）

## 快速开始

### 激活 Skill


### 示例对话

**问**：「两家公司正在打价格战，都知道继续打下去对谁都没好处，但谁都不敢先涨价，怎么用博弈论分析？」

**答**（Skill 视角）：

```
这是一个典型的囚徒困境。

参与人：A公司、B公司
策略空间：降价、涨价
收益结构：
  - 都维持价格：各赚100万
  - 都降价：各赚50万
  - A降价B涨价：A赚150万，B亏50万
  - B降价A涨价：B赚150万，A亏50万

纳什均衡分析：
  - 给定B维持价格，A降价（150 > 100）→ 降价是最优反应
  - 给定B降价，A降价（50 > -50）→ 降价是最优反应
  → (降价, 降价) 是纳什均衡

问题根源：
  - 背叛的诱惑（150万）> 合作的收益（100万）
  - 单方面背叛的收益总是正的

破局路径：
  1. 改变收益结构：差异化竞争，降低正面冲突
  2. 引入外部约束：行业协会限价协议（反垄断法允许范围内）
  3. 重复博弈：如果这是长期关系，引入未来惩罚机制
```

> 说明：当前版本已加入「触发→建模→均衡→破局」的固定执行逻辑，默认会在信息不完整时给出基线假设并继续分析。

## 核心能力

### 1. 博弈结构识别

| 博弈类型 | 识别特征 | 典型场景 |
|---------|---------|---------|
| 囚徒困境 | 合作对双方都好，但背叛是占优策略 | 价格战、碳排放、公共品 |
| 智猪博弈 | 一方搭便车，搭便车是理性选择 | 大企业创新、小企业模仿 |
| 懦夫博弈 | 两败俱伤的风险让双方犹豫 | 军备竞赛、市场争夺 |
| 协调博弈 | 多个均衡，需要协调机制 | 技术标准、靠哪边开车 |
| 信号博弈 | 信息不对称，信号传递类型 | 学历、认证、广告 |
| 猎鹿博弈 | 合作收益高，但有风险 | 创业联盟、国际合作 |

### 2. 纳什均衡求解

完全信息静态博弈 → 找稳定策略组合

完全信息动态博弈 → 逆向归纳法

不完全信息博弈 → 贝叶斯均衡

### 3. 破局分析

- 改变收益结构
- 改变信息结构
- 引入外部约束
- 改变博弈规则
- 引入新玩家

## 局限与边界

这个 Skill：

- ✅ 能帮你快速识别博弈结构和均衡
- ✅ 能提供破局的可能路径
- ✅ 能用博弈论语言重新框定问题

但有限制：

- ❌ 不能替代专业博弈论分析
- ❌ 不能处理非常复杂的动态博弈
- ❌ 不能保证给出的建议在现实中可行
