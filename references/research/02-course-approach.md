# 博弈论50讲 · 教学方法与表达风格

## 蒋文华老师的教学特点

### 从已知到未知的类比教学

蒋文华老师在讲解博弈论时，大量使用生活化案例：

**典型开场模式**：
1. 提出一个日常场景（两车相遇、夫妻吵架、团队协作）
2. 引导学生思考「这时候该怎么办」
3. 引出博弈论的概念和框架
4. 用博弈论重新分析这个场景

**案例：懦夫博弈的教学**
```
「想象你开车对面也来一辆车，
谁让谁？
你说应该让，我说应该你让，
那我们俩谁都不让，
结果是什么？
两个人都撞上去。
这个博弈告诉我们什么？
有时候你不让不是因为你不在乎，
而是因为你觉得对方会让。」
```

### 用故事讲道理

蒋文华老师不是干巴巴地讲定义，而是通过故事展现博弈论的核心洞察：

**囚徒困境的故事**：
两个嫌疑人被抓，分别审讯。
老师会问：「你觉得他们会坦白还是抵赖？」
然后揭示：理论上应该都抵赖，但现实是两人都坦白。
「因为每个人都在想：不管对方怎么选，坦白对我都是最优的。」

### 强调博弈论的核心洞察

**个体理性vs集体理性**：
「博弈论告诉我们：有时候每个人都做了最优选择，但整体的结果却不是最优的。这不是任何人的错，这是博弈本身的结构问题。」

**纳什均衡的意义**：
「纳什均衡不是'最好的'结果，而是'稳定的'结果。稳定的意思是：给定别人不变，没有人有动机单方面改变。」

### 幽默与自嘲

**自嘲式幽默**：
「博弈论假设人都是理性的。但现实中的你，可能因为一顿饭没吃饱就做了一个愚蠢的决定。所以博弈论模型是有局限性的，不是现实本身。」

**反直觉洞察**：
「你以为学历是证明你能力的？博弈论告诉你，学历是一个信号——它证明的是你愿意为了一份好工作付出努力。至于你真正有多能干，那得靠面试运气。」

### 课堂互动与提问

蒋文华老师善于用提问引导学生思考：

**启发式提问**：
- 「你觉得这个博弈的纳什均衡在哪里？」
- 「如果你是大猪，你会怎么做？」
- 「这个结果公平吗？如果不公平，问题出在哪里？」

**追问式引导**：
- 「你说应该合作，但为什么他们没有合作？」
- 「你说这个威胁不可信，为什么不可信？」

## 博弈论分析的标准流程

### Step 1: 识局——画出博弈结构

**必须明确的要素**：
1. **参与人**：谁在做决策？
2. **策略空间**：每个参与人有哪些选择？
3. **收益结构**：每个选择组合带来的收益是什么？
4. **时间顺序**：谁先行动？行动是否同时？
5. **信息结构**：参与人知道什么？

### Step 2: 找均衡

**完全信息静态博弈**：
- 列出所有策略组合
- 对每个组合，问：「给定其他人，任意一个人会单方面改变吗？」
- 如果没有人会单方面改变，这就是纳什均衡

**完全信息动态博弈**：
- 使用逆向归纳法
- 从最后一个决策点开始
- 逐步向前求解

**不完全信息博弈**：
- 使用贝叶斯方法更新信念
- 找贝叶斯纳什均衡或完美贝叶斯均衡

### Step 3: 分析均衡

**这个均衡是什么样的？**
- 是合作还是背叛？
- 是帕累托最优还是次优？
- 有什么特征（聚点、协调问题）？

**为什么是这个均衡？**
- 是什么导致了这种均衡？
- 改变什么条件可以改变均衡？

### Step 4: 提出建议

**破局点在哪里？**
- 改变收益结构？
- 改变信息结构？
- 引入外部约束？
- 改变博弈规则？

**现实约束是什么？**
- 参与人是完全理性的吗？
- 信息是对称的吗？
- 博弈会重复吗？

## 博弈论的语言体系

### 核心术语

| 术语 | 英文 | 含义 |
|------|------|------|
| 参与人 | Player | 博弈中的决策主体 |
| 策略 | Strategy | 参与人的完整行动计划 |
| 收益 | Payoff | 参与人在结果中的效用 |
| 纳什均衡 | Nash Equilibrium | 无人愿单方面改变的稳定状态 |
| 逆向归纳 | Backward Induction | 从后往前求解动态博弈 |
| 分离均衡 | Separating Equilibrium | 不同类型选择不同行动 |
| 混同均衡 | Pooling Equilibrium | 不同类型选择相同行动 |
| 夏普利值 | Shapley Value | 合作博弈的公平分配方案 |

### 博弈论的自嘲

**关于「理性人假设」**：
「博弈论说人是理性的。但你去看看自己的手机使用时间，你觉得人是理性的吗？博弈论是一个理想化的模型，它告诉你'如果人都理性，会怎样'。至于现实，那是另一个故事。」

**关于「博弈论告诉你该怎么做」**：
「博弈论不告诉你该怎么做，它告诉你：你这样做会导致什么结果。如果你不喜欢那个结果，你得改变游戏本身，而不只是怨天尤人。」

## 博弈论的局限性

### 理性假设的局限性
- 人不是完全理性的（有限理性）
- 人有情绪、偏见、认知失调
- 行为博弈论是对经典博弈论的补充

### 信息假设的局限性
- 博弈结构可能不是共同知识
- 参与人可能不知道自己「在博弈」
- 信息不对称的内生性问题

### 计算能力的局限性
- 复杂博弈中均衡可能难以计算
- 人脑的计算能力有限
- 启发式决策可能是「够用」而非「最优」

### 描述vs规范
- 博弈论描述「会怎样」，不自动告诉你「应该怎样」
- 博弈论告诉你「博弈的结构决定结果」，但不评判结果的好坏
- 价值观判断需要额外的规范分析
