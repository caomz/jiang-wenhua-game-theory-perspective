# 博弈论50讲 · 分析框架与工具箱

## 博弈分析决策树

### 第一步：识别博弈类型

```
问题：这个博弈的时间结构和信息结构是什么？
│
├── 完全信息？
│   ├── 静态博弈（同时行动）→ 找纳什均衡
│   └── 动态博弈（有先后顺序）→ 逆向归纳法
│
└── 不完全信息？
    ├── 静态博弈 → 贝叶斯纳什均衡
    └── 动态博弈 → 完美贝叶斯均衡
```

### 第二步：识别参与人和策略

**必须明确**：
1. 有哪些玩家？
2. 每个玩家的策略空间是什么？
3. 策略是有限还是无限的？
4. 行动是否同时？

### 第三步：确定收益结构

**必须明确**：
1. 每个策略组合的收益是什么？
2. 收益是ordinal（只比较大小）还是cardinal（具体数值）？
3. 参与人的偏好是什么？

### 第四步：求解均衡

**完全信息静态博弈**：
1. 列出所有策略组合
2. 对每个组合检查：「给定其他人，谁想单方面改变？」
3. 没有人想改变 = 纳什均衡

**完全信息动态博弈**：
1. 从最后一个决策点开始
2. 每个决策点，参与人选择最优行动
3. 回溯到前一个决策点
4. 直到起点

**不完全信息博弈**：
1. 确定先验分布
2. 使用贝叶斯法则更新信念
3. 找贝叶斯均衡

### 第五步：分析均衡

1. 均衡是合作还是背叛？
2. 均衡是帕累托最优还是次优？
3. 有没有其他均衡？哪个更「合理」？
4. 均衡的稳健性如何？

## 经典博弈分析模板

### 囚徒困境分析模板

```
【囚徒困境分析】

参与人：A、B
策略空间：A（坦白，抵赖）× B（坦白，抵赖）
收益结构：
  - 都坦白：(5, 5) 各判5年
  - 都抵赖：(1, 1) 各判1年
  - A坦白B抵赖：(0, 10) A释放，B判10年
  - A抵赖B坦白：(10, 0) A判10年，B释放

纳什均衡分析：
  - 给定B坦白，A坦白（0 vs 5年）→ 坦白是A的最优反应
  - 给定B抵赖，A坦白（0 vs 1年）→ 坦白是A的最优反应
  - 同理，B坦白也是B的最优反应
  → (坦白, 坦白) 是纳什均衡

核心洞察：
  - 个体理性与集体理性的冲突
  - 背叛是占优策略
  - (抵赖, 抵赖) 帕累托优于 (坦白, 坦白)

破局路径：
  1. 重复博弈：引入未来惩罚
  2. 外部约束：强制合作协议
  3. 改变收益结构：提高抵赖的收益
```

### 智猪博弈分析模板

```
【智猪博弈分析】

参与人：大猪、小猪
策略空间：大猪（按杠杆，不按杠杆）× 小猪（按杠杆，不按杠杆）
收益结构：
  - 都按：(4, 1) 大猪4，小猪1
  - 大猪按小猪不按：(5, 0) 大猪5，小猪0
  - 小猪按大猪不按：(9, -1) 大猪9，小猪死
  - 都不按：(1, 1) 各1

纳什均衡分析：
  - 给定小猪按杠杆，大猪按杠杆(4) vs 不按杠杆(9) → 不按是最优反应
  - 给定小猪不按杠杆，大猪按杠杆(5) vs 不按杠杆(1) → 按杠杆是最优反应
  - 给定大猪按杠杆，小猪按杠杆(1) vs 不按杠杆(0) → 按杠杆是最优反应
  - 给定大猪不按杠杆，小猪按杠杆(-1) vs 不按杠杆(1) → 不按是最优反应
  → (不按, 按) 不是均衡
  → 真正的纳什均衡是 (按, 不按) —— 大猪按，小猪等

核心洞察：
  - 搭便车是理性选择
  - 但个体理性导致集体次优
  - 大猪的激励问题

政策含义：
  - 专利保护：为创新提供足够的激励
  - 补贴小猪：让小猪也有生存空间
```

## 博弈论工具箱

### 工具1：博弈矩阵

用于分析完全信息静态博弈。

```
标准格式：

收益矩阵（A的收益, B的收益）

|          | B行动1  | B行动2  |
|----------|---------|---------|
| A行动1   | (a1,b1)| (a2,b2) |
| A行动2   | (a3,b3)| (a4,b4) |
```

**分析步骤**：
1. 画矩阵
2. 对每个格子，问：「给定对方的选择，A/B会选什么？」
3. 找最优反应
4. 找共同的最优反应组合 = 纳什均衡

### 工具2：博弈树

用于分析完全信息动态博弈。

```
标准格式：

        A
      /   \
    B1     B2
   / \    / \
  ...  ...  ...

每个节点：
- 决策权归属
- 可选行动
- 到达该节点的概率（贝叶斯更新）
- 该节点的收益
```

**分析步骤**：
1. 画博弈树
2. 从叶子节点（终点）开始
3. 在每个决策点，标记最优选择
4. 回溯，用最优选择替换子树
5. 直到根节点

### 工具3：支付等值线

用于分析连续策略博弈。

```
等值线图：

策略A
  ↑
  |
  |     *最优
  |   ·
  | ·
  |· ·
  +---------→ 策略B

每条线代表相同的收益水平
```

### 工具4：最佳反应曲线

用于找纳什均衡。

```
        A的最佳反应
  ↑
  |
  |     · · · · ·
  |   ·
  | ·       *
  |· ·
  +---------→ B的选择
      ·
      · B的最佳反应

交叉点 = 纳什均衡
```

## 均衡求解速查

### 完全信息静态博弈

| 博弈类型 | 求解方法 | 均衡特征 |
|---------|---------|---------|
| 囚徒困境 | 占优策略 | 背叛是占优策略均衡 |
| 智猪博弈 | 重复剔除 | 大猪按小猪等 |
| 协调博弈 | 找聚点 | 可能多均衡 |
| 混合策略 | 最优反应随机化 | 预期收益相等 |

### 完全信息动态博弈

| 博弈类型 | 求解方法 | 均衡特征 |
|---------|---------|---------|
| 蜈蚣博弈 | 逆向归纳 | 有限次提前终止 |
| 承诺博弈 | 逆向归纳 + 可信性 | 承诺影响均衡 |
| 重复博弈 | 触发策略 | 合作均衡可能 |

### 不完全信息博弈

| 博弈类型 | 求解方法 | 均衡特征 |
|---------|---------|---------|
| 信号博弈 | 完美贝叶斯均衡 | 分离/混同/准分离 |
| 市场进入 | 贝叶斯纳什均衡 | 混合策略进入 |
| 拍卖 | 贝叶斯纳什均衡 | 策略因拍卖形式而异 |

## 常见错误与规避

### 错误1：混淆均衡和最优

**错误**：「纳什均衡是所有可能结果中最优的」

**正确**：「纳什均衡是稳定的，但不一定是最优的」

### 错误2：忽视多重均衡

**错误**：「这个博弈有一个唯一均衡」

**正确**：「需要检查是否有多个纳什均衡，再判断哪个更'合理'」

### 错误3：忽视混合策略

**错误**：「这个博弈没有纯策略均衡，所以没有均衡」

**正确**：「需要考虑混合策略均衡」

### 错误4：忽视时间顺序

**错误**：「囚徒困境是囚徒困境，不管谁先坦白」

**正确**：「如果是动态博弈（如警方可以威胁），结构可能不同」

### 错误5：忽视理性假设

**错误**：「博弈论说人们会这样做，所以人们就这样做」

**正确**：「博弈论描述的是理性情况，现实中的人有偏见、有情绪」
